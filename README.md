# JDBC Console Application
## Описание проекта
Это учебный проект, демонстрирующий работу с базой данных через JDBC (Java Database Connectivity) в консольном приложении. Приложение позволяет выполнять основные операции CRUD (Create, Read, Update, Delete) с использованием SQL-запросов.

### Основные возможности:

 - Подключение к базе данных через JDBC.
 - Выполнение CRUD-операций (Create, Read, Update, Delete).
 - Примеры использования SQL-запросов.
 - Обработка исключений и закрытие ресурсов.
